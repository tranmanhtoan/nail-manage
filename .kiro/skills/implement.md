# Triển khai

Triển khai công việc được mô tả bởi user trong spec hoặc tickets.

1. Dùng `/tdd` khi có thể, tại các seam đã thống nhất trước.
2. Chạy typecheck thường xuyên, chạy từng file test thường xuyên, và chạy toàn bộ test suite một lần ở cuối.
3. Xong thì dùng `/code-review` để review công việc.
4. Commit vào branch hiện tại.
