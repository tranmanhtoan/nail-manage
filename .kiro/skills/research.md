# Nghiên cứu

Điều tra câu hỏi dựa trên **nguồn chính** — doc chính thức, source code, spec, first-party API — không phải bài viết thứ cấp.

## Quy trình

1. Theo dõi mọi tuyên bố ngược về nguồn sở hữu nó.
2. Viết findings vào một file Markdown duy nhất, trích dẫn nguồn cho mỗi tuyên bố.
3. Lưu nơi repo đã giữ các ghi chú tương tự; khớp convention hiện có. Nếu không có, đặt nơi hợp lý và nói rõ ở đâu.
